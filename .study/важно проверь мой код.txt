2.15. Воспользуйтесь следующими соображениями. Обозначим

размер одной фигуры (первое число, введённое пользователем) бук-вой Н, а количество фигур (второе число) — буквой №. Весь ваш вы-вод состоит из № отдельных колонок, имеющих ширину Н+1 символ, причём в каждой колонке (с номером к) первые ѕk строк «пустые», т. е. состоящие из Н + 1 пробелов, затем Н строк составляют иско-мую фигуру, и последующие строки (с номерами, превышающими Sk + H) опять «пустые». Пусть h = (Н − 1)/2 (та самая «полови-на высоты» фигуры); тогда (если колонки нумеруются с единицы) S1 = 0, $2 = һит.д.; общая высота всего изображения при N = 1 составляет Н, а при увеличении № на единицу эта общая высота увеличивается на h; общие формулы для Sk и высоты изображения получите сами. После этого останется сообразить, что внутри «бук-вы Z» (если её строки занумеровать с единицы) строки с номерами 1, h+1 и Н состоят из Н звёздочек и пробела (отделяющего следую-щую фигуру от предыдущей), все остальные из одной звёздочки, перед и после которой нужно напечатать определённое число пробе-лов (как оно вычисляется попробуйте сообразить самостоятельно).

Процедура, печатающая п-ю строку к-й колонки изображения состоящую из одних пробелов, из одних звёздочек или из одной звёз-дочки с пробелами спереди и сзади, должна знать только число Н и, конечно, числа п и к, то есть у неё будет три целочисленных па-раметра; всё остальное она просто вычислит. Обязательно напишите эту процедуру! Это ключ к решению всей задачи. Главная програм-ма будет состоять из простых вложенных циклов for: внешний для печати строк от первой до только что вычисленной общей высо-ты фигуры, внутренний для печати нужной строки от каждой из № колонок (путём вызова вышеупомянутой процедуры). Не забудьте про перевод строки после печати всех колонок, относящихся к одной строке!
